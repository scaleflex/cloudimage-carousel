CloudImage Carousel

Two initialization methods — JavaScript API and HTML data-attributes

1. JavaScript API

const carousel = new CloudImageCarousel('#carousel-js', {
  images: ['hotel.jpg', 'birds.jpg', ...],
  theme: 'light',
  showBullets: true,
  transitionEffect: 'slide',
})
carousel.init()

2. HTML Data Attributes + autoInit()

<div
  data-ci-carousel-images='["hotel.jpg", "birds.jpg", ...]'
  data-ci-carousel-theme="dark"
  data-ci-carousel-show-bullets="true"
  data-ci-carousel-transition="fade"
></div>

<script>CloudImageCarousel.autoInit()</script>

3. Coverflow (openbook) layout

new CloudImageCarousel('#carousel-coverflow', {
  images: [...],
  showCoverflow: true,    // active slide centered, 2 neighbors each side
  cycle: true,            // wraps at boundaries — no grey tiles
  showBullets: true,
  showThumbnails: false,
})

4. Overlap transition (drag to navigate)

new CloudImageCarousel('#carousel-overlap', {
  images: [...],
  transitionEffect: 'overlap', // incoming image slides OVER the current one
  cycle: true,
  showBullets: true,
})

Drag the image left/right (mouse or touch) — the next/prev image rides over the current one and snaps on release.
